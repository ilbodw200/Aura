# Проверка Android 1.0.3

[Сборка и проверки](https://github.com/ilbodw200/Aura/actions/runs/41233827926) завершились успешно: JVM-тесты, восемь инструментальных тестов Android 15 и запуск подписанного release APK.

Новый сценарий открывает настройки через верхнюю иконку, выбирает HEAD, сохраняет его, затем выбирает TCP и закрывает страницу без сохранения. В хранилище остаётся HEAD. Также проходят прежние проверки прокрутки 57 серверов, выбора и сохранения последнего, native-ядра и GET/HEAD через тестовый SOCKS-сервер.

Снимки главного экрана, настроек и пинга из эмулятора просмотрены. Сертификат совпадает с 1.0.2: SHA-256 `a93259e2ba7574b5ed6565cc570ed26a1e8bb1271a3fda5eecc000570822443e`. Версия APK — 1.0.3 (7), Android 8.0+, arm64-v8a / armeabi-v7a / x86_64.

Исходники iOS в этом обновлении не менялись. Подключение к серверу провайдера на физическом устройстве этими проверками не подтверждается.
