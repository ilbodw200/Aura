# HWID и подключение iOS 0.1.1

## Ошибка «App Group недоступна»

В 0.1.0 главный процесс передавал конфигурацию через общий контейнер `group.app.aura.proxy`. При сторонней подписи доступ к этой группе мог отсутствовать. В 0.1.1 конфигурация передаётся через `NETunnelProviderProtocol.providerConfiguration` и параметры запуска VPN, а ядро использует собственную папку расширения. **App Group больше не нужна.**

Фактический bundle ID расширения читается из встроенного `AuraTunnel.appex`, поэтому изменение идентификатора расширения при подписи не обязано совпадать с исходным ID проекта.

Подпись всё равно должна разрешать **Network Extension / packet-tunnel-provider**. Изменение кода не может добавить отсутствующие разрешения в provisioning profile. Подписать нужно и главное приложение, и расширение. Код не пытается обходить проверку подписи iOS.

## Включение HWID

1. Установите IPA версии 0.1.1 с вашей подписью.
2. Откройте **Серверы → кнопка настроек рядом с подпиской → Отправка HWID → Отправлять HWID**.
3. Сохраните настройку и нажмите **обновить** у подписки.
4. Если провайдер привязывает доступ вручную, скопируйте идентификатор в **Настройки → Устройство и HWID → Скопировать HWID** и передайте ему.

Глобальное значение используется для подписок, у которых выбрано «Как в настройках приложения». При первом импорте есть отдельный переключатель HWID.

Отправляются заголовки `X-HWID`, `X-Device-OS`, `X-Ver-OS`, `X-Device-Model`, `X-Device-Info`. Отправка выключена по умолчанию, доступна только HTTPS. При перенаправлении на другой сервер заголовки идентификатора удаляются. Пароли и HWID не записываются в журнал действий.

HWID AURA — устойчивый идентификатор приложения в Keychain на iOS и идентификатор установки на Android. Он не является аппаратным серийным номером и не совпадает с HWID Happ. Копии профилей не переносят этот идентификатор на другой телефон. Провайдеру может понадобиться освободить слот или заново привязать устройство.

## Служебный профиль 0.0.0.0:1

Некоторые серверы возвращают такой профиль вместо рабочего сервера, если требуют привязку HWID или изменение настроек. AURA не будет пытаться подключаться к нулевому адресу: она покажет подсказку включить HWID и обновить подписку. Само включение заголовка не выдаёт доступ и не заменяет активную подписку у провайдера.
