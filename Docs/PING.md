# Пинг в AURA 1.0

Откройте **Настройки → Настройки пинга** либо шестерёнку на главном экране. Выберите метод, таймаут 5–15 секунд и сохраните. Кнопка задержки в строке проверяет один сервер; спидометр в заголовке — группу. Групповую проверку можно остановить после текущих запросов.

| Метод | Что измеряется |
| --- | --- |
| Через прокси GET | Запрос GET к URL теста через выбранный профиль, до получения HTTP-заголовков |
| Через прокси HEAD | Запрос HEAD тем же путём, без загрузки тела |
| TCP | Установка TCP-соединения с адресом и портом сервера |
| ICMP | IPv4 Echo Request/Reply к адресу сервера |

Для GET/HEAD создаётся отдельный экземпляр ядра без TUN. Запрос направляется строго в outbound выбранного профиля; прямого HTTP-запроса при отказе прокси нет. Подключать VPN или менять активный профиль для проверки не требуется. Настройка маршрутизации «Напрямую» не подменяет этот тест прямым запросом.

Режим **Default** делает один запрос. **Double** делает два с отключённым Keep-Alive и показывает лучший успешный результат. **Keepalive** делает два запроса с разрешённым повторным использованием соединения и также выбирает лучший. Фактическое повторное использование зависит от сервера. Таймаут ограничивает весь тест, а не каждый из двух запросов отдельно. Погрешность измерения — миллисекунды; значения округляются минимум до 1 мс.

URL по умолчанию — `https://www.gstatic.com/generate_204`. Можно указать другой HTTP/HTTPS-адрес без логина и пароля. Проверка сертификата HTTPS включена. Перенаправления не выполняются: отображается код первоначального ответа. В настройках можно заменить время в списке на HTTP-статус. Получение, например, 403 доказывает ответ сайта, но не означает успешный доступ к нему. Это проверка задержки, а не скорости загрузки.

TCP и ICMP используют текущий сетевой маршрут. На iOS при включённом VPN он может проходить через туннель; Android исключает собственное приложение из своего VPN для управления соединением. TCP не подтверждает работу UDP-протокола Hysteria2. ICMP доступен не во всех сетях и версиях ОС; отсутствие ответа не означает, что прокси не работает. AURA не подменяет неудачный ICMP другим методом.

Результат подписан методом измерения. При ошибке прежнее время очищается, чтобы оно не выглядело свежим результатом. Для групп iOS выполняет не более двух параллельных тестов, Android — по одному. Сохранённые профили и подписки версии 0.1.x остаются совместимыми; при отсутствии настроек используется GET / Default / 7 секунд.

Информация о трафике и сроке действия берётся только из заголовка провайдера `subscription-userinfo`. Отсутствующие данные не выдумываются; `total=0` означает отсутствие указанного лимита и отображается как ∞.
