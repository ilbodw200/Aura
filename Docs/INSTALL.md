# Установка AURA

Скачайте файлы из [AURA 0.1.1](https://github.com/ilbodw200/Aura/releases/tag/v0.1.1).

## Android

Откройте `AURA-Android-0.1.1.apk` на Android 8.0+ и разрешите установку выбранному браузеру или файловому менеджеру. APK уже подписан. При первом подключении Android запросит разрешение VPN. Собственные серверы добавляются во вкладке «Серверы».

## iPhone / iPad

`AURA-iOS-0.1.1-unsigned.ipa` нужно подписать вместе с вложенным `AuraTunnel.appex` вашим сертификатом и provisioning profiles, разрешающими Network Extension / packet-tunnel-provider. **App Group в 0.1.1 не нужна.** Фактический ID расширения читается из встроенного бандла после подписи.

Открытие IPA в приложении «Файлы» не устанавливает его автоматически — используйте ваш способ подписи и установки. Приложение поддерживает iOS 17+, Liquid Glass — iOS 26+.

## HWID

Серверы → настройки нужной подписки → Отправлять HWID → Сохранить → Обновить. На Android настройка расположена в карточке подписки, на iOS — за кнопкой настроек рядом с ней. Идентификатор копируется в настройках устройства AURA.

Если подписка была привязана к другому клиенту, провайдеру может потребоваться новая привязка. Подробности — [HWID и подпись](HWID-AND-SIGNING.md).

## Самостоятельная сборка

iOS на Mac: `brew install xcodegen go`, затем `AURA_TEAM_ID=ABCDEFGHIJ bash Scripts/build-ipa.sh signed full`. Войдите в свой аккаунт разработчика в Xcode. Без Mac используйте workflow `Build unsigned iPhone IPA`.

Android: [инструкция сборки](../Android/README.md). Облачный workflow `Android APK build and tests` использует постоянный ключ из GitHub Actions Secrets.

Проверки сборки и эмуляторов не заменяют тест VPN на реальном устройстве с вашим сервером. Актуальный статус и ограничения — в README и описании релиза.
