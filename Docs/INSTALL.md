# Установка AURA 1.0

Скачайте файлы из [единого релиза](https://github.com/ilbodw200/Aura/releases/tag/v1.0).

## Android

Откройте **AURA-Android-1.0.apk** на Android 8.0+ и разрешите установку выбранному браузеру или файловому менеджеру. APK подписан постоянным ключом; versionCode 8 позволяет установить обновление поверх прежних сборок с сохранением данных.

Добавьте свою подписку через «Серверы → +» или нижнюю панель на главной. Для HTTPS предварительная проверка необязательна. Для HTTP требуется согласие на незашифрованную загрузку и проверка формата. Подключение запрашивает системное разрешение VPN.

Поиск, сортировка, избранное и автовыбор доступны во вкладке серверов. Доступность определяется результатом настоящей проверки. Смена подключённого сервера выполняет остановку и запуск новой сессии.

## iPhone / iPad

Подпишите **AURA-iOS-1.0-unsigned.ipa** и вложенное **AuraTunnel.appex** сертификатом и provisioning profiles, разрешающими Network Extension / packet-tunnel-provider. App Group не нужна. Установите через ваш инструмент подписи, сохранив идентификаторы приложения и расширения при обновлении.

Открытие IPA в «Файлах» само по себе не устанавливает приложение. iOS 17+, Liquid Glass на iOS 26+. Оформление iPhone сохранено.

## HWID

Откройте управление нужной подпиской, включите отправку HWID и обновите её. HWID — идентификатор установки AURA, не IMEI. Провайдеру может потребоваться новая привязка при переходе с другого клиента.

## Always-on и Kill Switch

В Android откройте «Настройки → Auto Connect / Always-on» и выберите параметры AURA. «Блокировать соединения без VPN» включает системный Lockdown. Приложение не может молча менять эти системные разрешения.

Контрольные суммы APK, IPA и архива исходников приложены к релизу. [Исходная сборка Android](../Android/README.md).
