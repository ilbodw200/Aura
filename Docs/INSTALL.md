# Установка AURA

Скачайте [iOS 1.0.2](https://github.com/ilbodw200/Aura/releases/tag/v1.0.2) или [Android 1.0.2](https://github.com/ilbodw200/Aura/releases/tag/v1.0.2).

## Android

Откройте `AURA-Android-1.0.2.apk` на Android 8.0+ и разрешите установку выбранному браузеру или файловому менеджеру. APK уже подписан. При первом подключении Android запросит разрешение VPN. Собственные серверы добавляются через меню ⚙ → Добавить подключение. Нажмите нижнюю карточку для поиска и выбора сервера; настройки подписок доступны через верхний переключатель → Управление подписками.

## iPhone / iPad

`AURA-iOS-1.0.2-unsigned.ipa` нужно подписать вместе с вложенным `AuraTunnel.appex` вашим сертификатом и provisioning profiles, разрешающими Network Extension / packet-tunnel-provider. **App Group не нужна.** Фактический ID расширения читается из встроенного бандла после подписи.

HTTPS-подписка добавляется сразу кнопкой «Добавить подписку»; предварительная проверка необязательна. Для HTTP нужно принять предупреждение и проверить ссылку перед сохранением. TLS-сертификаты HTTPS не игнорируются.

Открытие IPA в приложении «Файлы» не устанавливает его автоматически — используйте ваш способ подписи и установки. Приложение поддерживает iOS 17+, Liquid Glass — iOS 26+.

## HWID

Серверы → настройки нужной подписки → Отправлять HWID → Сохранить → Обновить. На Android настройка расположена в карточке подписки, на iOS — за кнопкой настроек рядом с ней. Идентификатор копируется в настройках устройства AURA.

Если подписка была привязана к другому клиенту, провайдеру может потребоваться новая привязка. Подробности — [HWID и подпись](HWID-AND-SIGNING.md).

## Самостоятельная сборка

iOS на Mac: `brew install xcodegen go`, затем `AURA_TEAM_ID=ABCDEFGHIJ bash Scripts/build-ipa.sh signed full`. Войдите в свой аккаунт разработчика в Xcode. Без Mac используйте workflow `Build unsigned iPhone IPA`.

Android: [инструкция сборки](../Android/README.md). Облачный workflow `Android APK build and tests` использует постоянный ключ из GitHub Actions Secrets.

Проверки сборки и эмуляторов не заменяют тест VPN на реальном устройстве с вашим сервером. Актуальный статус и ограничения — в README и описании релиза.
