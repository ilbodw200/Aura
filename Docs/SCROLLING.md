# Прокрутка списка серверов — iOS 1.0.2

На экране «Обзор» серверы теперь расположены в нативном `List`, отдельными строками и секциями подписок. Один большой стеклянный слой поверх всей длинной подписки удалён; стеклянные элементы остаются у кнопок и системных панелей.

Список можно листать жестом по строкам. Состояние раскрытых подписок хранится на уровне экрана и сохраняется, когда строки уходят за границы видимой области. Кнопки «Скрыть все» и «Показать все» работают с теми же секциями.

В нижней панели доступны выбранный сервер, состояние VPN, кнопка подключения/отключения и «Наверх». Панель учитывается безопасными отступами списка; последняя строка доступна над элементами управления. Логика VPN, импорт подписок и HWID не изменены.

Для проверки добавлен сценарий `AuraScrolling`: он запускает debug-приложение с 57 тестовыми профилями, листает до последнего, выбирает его и возвращается к большой кнопке подключения. Снимки экрана сохраняются в результате теста. Профили используют `.example.invalid`; тест не обращается к хранилищу и не запускает VPN. В релизном IPA этот режим отсутствует.

Для установки подпишите `AURA-iOS-1.0.2-unsigned.ipa` вместе с `AuraTunnel.appex` вашим сертификатом с Network Extension и установите поверх 1.0.1. Подписки и настройки сохраняются. Android в этом обновлении не менялся; для него остаётся APK 1.0.1.
