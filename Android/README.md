# AURA для Android

Нативное приложение Android 8.0+ (API 26) со стеклянным оформлением, VPN через `VpnService` и sing-box v1.11.15. APK содержит armeabi-v7a, arm64-v8a и x86_64. Это developer preview; полный паритет с Happ не заявляется.

## Возможности

- Импорт ссылок, текстовых файлов, QR и HTTPS-подписок: VLESS/Reality, VMess, Trojan, Shadowsocks, SOCKS5, Hysteria2.
- TCP, WebSocket, gRPC, HTTP в генераторе конфигураций; неизвестные параметры отклоняются.
- Отправка HWID и сведений об устройстве только при включении в настройках подписки. HWID — случайный идентификатор установки AURA, а не IMEI или серийный номер.
- Правила доменов, суффиксов, ключевых слов, IPv4/CIDR; direct/proxy/block; порядок и проверка маршрута.
- Исключение выбранных приложений из VPN, обход LAN, DoH, избранные серверы, TCP-задержка.
- Пять акцентов, четыре фона, тёмная/светлая/системная тема, радиус, компактность, скрытие и порядок блоков.
- AES-256-GCM-хранилище с ключом Android Keystore; зашифрованные копии с PBKDF2-SHA256 (210 000 итераций).

Подписки и серверы не предоставляются. XHTTP и фирменные зашифрованные ссылки Happ пока не поддерживаются. При переходе с другого клиента провайдеру может понадобиться новая привязка HWID.

## Установка

Скачайте подписанный APK из [Releases](https://github.com/ilbodw200/Aura/releases). Разрешите установку APK тому приложению, через которое открываете файл. Системное разрешение VPN запрашивается при первом подключении. Подпись APK уже выполнена; iOS-сертификат для Android не нужен.

Для привязки подписки: **Серверы → Настройки подписки → Отправлять HWID → Сохранить → Обновить**. HWID можно скопировать в **Ещё → HWID устройства**. При переустановке с удалением данных идентификатор установки изменится.

## Сборка и проверка

Требуются JDK 17, Android SDK 35, NDK 28.0.13004108, Go 1.24.2. На Linux/macOS из корня репозитория:

```bash
bash Scripts/bootstrap-android-core.sh
cd Android
./gradlew testReleaseUnitTest assembleDebug
```

Для release-сборки задаются `AURA_SIGNING_STORE` (PKCS12, alias `aura`) и `AURA_SIGNING_PASSWORD`. Ключ релиза хранится в зашифрованных GitHub Actions Secrets, не в исходниках. Не меняйте ключ при выпуске обновлений: Android требует одинаковую подпись.

Workflow **Android APK build and tests** собирает библиотеку, запускает JVM-тесты, проверяет подпись APK, выполняет два теста на эмуляторе Android 15 (загрузка native-ядра, проверка конфигураций шести протоколов, запуск Activity), затем устанавливает и запускает подписанный release APK. Сетевое подключение к реальному серверу на физическом телефоне этим не подтверждается.
