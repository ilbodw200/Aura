# AURA VPN 1.0

Нативный VPN-клиент для Android и iPhone. Собственные серверы и подписки добавляются пользователем.

[Релиз 1.0](https://github.com/ilbodw200/Aura/releases/tag/v1.0) · [Установка](Docs/INSTALL.md)

- **AURA-Android-1.0.apk** — подписанный APK для Android 8.0+, arm64-v8a / armeabi-v7a / x86_64.
- **AURA-iOS-1.0-unsigned.ipa** — iOS 17+, Liquid Glass на iOS 26+. Требуется подпись приложения и расширения с Network Extension.

## Android

Kotlin, Jetpack Compose, MVVM, Coroutines/StateFlow. Тёмное оформление Neon Purple и Cyber Blue, регулируемое свечение и отключение эффектов. Главная, серверы и настройки доступны через нижнюю навигацию; быстрый выбор сервера остаётся над ней.

Нативное ядро sing-box работает в foreground `VpnService`. Состояние туннеля, длительность сессии, скорость и объём трафика берутся из службы и счётчиков ядра. Проверка IP использует HTTPS через защищённый вход текущего прокси без прямого fallback. При отсутствии измерений показывается «—» или состояние проверки.

Серверы: поиск, фильтры подписок и протоколов, избранное, сортировка по задержке, групповая проверка и автовыбор по результатам измерений. Смена активного сервера сначала закрывает прежнюю сессию.

Настройки: запуск VPN при открытии приложения, восстановление сети, системные Always-on/Lockdown Android, DoH, блокировка IPv6, включение или исключение приложений, MTU, пинг, диагностика и экспорт отчёта без ключей и адресов подписок.

## Протоколы и данные

VLESS/Reality, VMess, Trojan, Shadowsocks, SOCKS5, Hysteria2. Поддерживаются предусмотренные парсером TCP, WebSocket, gRPC и HTTP. XHTTP, WireGuard-конфигурации и фирменные зашифрованные ссылки Happ не импортируются.

Импорт из ссылки, текста, QR и файла. HTTPS-подписку можно сохранить без предварительной загрузки; HTTP требует подтверждения и проверки. TLS-сертификаты не отключаются. HWID отправляется только при включении для конкретной подписки; это идентификатор установки, а не IMEI.

Секреты хранятся в AES-256-GCM-хранилище Android Keystore; оформление — в DataStore. Резервные копии шифруются пользовательским паролем. Нет аналитики и рекламы.

## iPhone

SwiftUI, прежнее оформление Liquid Glass, исправленная прокрутка длинных подписок и кнопка возврата наверх. App Group не требуется. Подпишите IPA и вложенное AuraTunnel.appex сертификатом с packet-tunnel-provider.

## Сборка и проверки

[Android: архитектура, сборка и ограничения](Android/README.md). [Проверка выпуска](Docs/VALIDATION-1.0.md).

Android: JDK 17, SDK 35, NDK 28.0.13004108, Gradle 8.11.1 и Go 1.24.2. `bash Scripts/bootstrap-android-core.sh`, затем `Android/gradlew -p Android testReleaseUnitTest assembleDebug`.

iOS: macOS, Xcode 26+, XcodeGen и Go 1.24.2. `bash Scripts/build-ipa.sh unsigned full`.
