## Добавление подписок

HTTPS-ссылку с замочком можно добавить сразу, без обязательной предварительной проверки. После сохранения список серверов обновляется отдельно; ошибки загрузки не удаляют ссылку. Проверка TLS-сертификата при загрузке остаётся включённой. Замок обозначает HTTPS, а не гарантию совместимости формата ответа.

HTTP без замочка требует явного разрешения незашифрованного соединения и успешной проверки доступности/формата этой же ссылки до сохранения. Проверка не добавляет шифрование. HWID по HTTP не отправляется, переход HTTPS → HTTP блокируется.

В iOS добавлены распространённые JSON-ответы Xray/sing-box и частичный импорт совместимых серверов с предупреждениями. Вместо общей ошибки отображается причина: HTTP-код, DNS, TLS, тайм-аут или несовместимая запись.

## Исправление App Group и HWID

В 0.1.1 **App Group больше не нужна**: конфигурация передаётся через системную конфигурацию VPN. Фактический ID расширения определяется по встроенному `AuraTunnel.appex`, включая изменение ID при сторонней подписи. Разрешение Network Extension в подписи всё равно обязательно.

Для существующей подписки: **Серверы → настройки подписки → Отправлять HWID → сохранить → обновить подписку**. HWID AURA можно скопировать в настройках приложения. Это идентификатор AURA, а не серийный номер телефона и не HWID Happ. Провайдеру может понадобиться новая привязка устройства. По умолчанию отправка выключена.

Подробности: [HWID и подпись](Docs/HWID-AND-SIGNING.md), [Android](Android/README.md).

## Возможности

VLESS/Reality, VMess, Trojan, Shadowsocks, SOCKS5, Hysteria2; импорт ссылок, файлов, QR, HTTPS-подписок; ручное обновление; избранное и GET/HEAD/TCP/ICMP-проверки; правила доменов, суффиксов, keywords и IPv4/CIDR с direct/proxy/block; DoH, обход LAN, зашифрованное хранилище и резервные копии. В Android доступно исключение приложений из VPN.

Оформление: пять акцентов, четыре фона, светлая/тёмная/системная тема, радиус, компактность, скрытие адресов и порядок блоков. iOS использует SwiftUI Liquid Glass; Android — нативные представления и стеклянные карточки.

## Сборка

**iOS:** Xcode 26+, XcodeGen. `bash Scripts/bootstrap-core.sh` собирает Libbox и генерирует `Aura.xcodeproj`. `AURA_TEAM_ID=ABCDEFGHIJ bash Scripts/build-ipa.sh signed full` архивирует подписанный IPA на Mac. Workflow `Build unsigned iPhone IPA` выполняет облачную сборку без подписи. Общие тесты: `swift test` на macOS.

**Android:** JDK 17, SDK 35, NDK 28.0.13004108, Go 1.24.2. `bash Scripts/bootstrap-android-core.sh`, затем `cd Android && ./gradlew testReleaseUnitTest assembleDebug`. Для release нужны `AURA_SIGNING_STORE` и `AURA_SIGNING_PASSWORD`. Постоянный ключ подписи хранится в зашифрованных GitHub Actions Secrets; исходники не содержат ключей и паролей.

## Проверено и ограничения

iOS: полная сборка с ядром, тесты конфигурации и HWID-запросов, запуск в симуляторе. Android: JVM-тесты, проверка подписи, восемь тестов Android 15 с загрузкой native-ядра, конфигурациями всех шести протоколов и настоящими GET/HEAD через тестовый SOCKS-сервер; подписанный release APK установлен и запущен в эмуляторе, снимок экрана проверен.

Реальное VPN-соединение на физических телефонах с вашими серверами и подписью требует отдельной проверки. Камера QR также требует проверки на устройстве. Полный паритет с Happ не достигнут: XHTTP и фирменные зашифрованные ссылки Happ пока не поддерживаются. Серверы и подписки не предоставляются.
