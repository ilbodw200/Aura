# AURA — iOS proxy utility

Нативный SwiftUI-проект с Liquid Glass на iOS 26 и системными материалами на iOS 17–18. Рабочая версия **0.1 / Developer Preview**, а не готовая замена Happ. Исходники созданы в этой папке; серверы и подписки не предоставляются.

**Установочный файл iPhone:** инструкция `Docs/INSTALL.md`. На Mac `bash "Build IPA.command"` запускает подготовленную сборку подписанного IPA. Без Mac подготовлен ручной workflow `.github/workflows/ipa.yml` для неподписанного IPA в GitHub Actions. Ни один IPA в текущей Windows-сессии не собран и не подписан.

## Что реализовано

- Обзор с кнопкой подключения, реальным статусом `NEVPNConnection`, выбранным сервером и избранным.
- Студия: пять акцентов, четыре фона, светлая/тёмная/системная тема, радиус карточек, компактность, уменьшение движения, скрытие адресов, скрытие и перестановка блоков.
- Импорт стандартных VLESS/Reality, VMess, Trojan, Shadowsocks SIP002/legacy, SOCKS5, Hysteria2; текст, файл, камера QR; HTTPS-подписки, предварительная проверка и ручное обновление.
- Поддержанные транспорты: TCP, WebSocket, gRPC, HTTP. Неизвестные параметры отклоняются, а не теряются молча. Поддержка конкретного сервера требует проверки ядром.
- Правила домена, суффикса, ключевого слова и IPv4/CIDR; действия proxy/direct/block, порядок, отключение и проверка совпадений. Режимы global/smart/direct, обход LAN, три DoH-провайдера.
- AES-GCM-хранилище с ключом в Keychain; копии с паролем (PBKDF2-SHA256, 210 000 итераций + AES-GCM); скрытие в переключателе приложений.
- TCP-задержка, журнал действий без адресов и ключей, экспорт журнала.
- Packet Tunnel Extension, адаптер Libbox, настройка VPN On Demand. Ядро собирается отдельно на Mac.

## Открыть на Mac

Требуются **Xcode 26+** и macOS, поддерживаемая Xcode. Подключение и Network Extension проверяются на физическом iPhone; нужен Apple Developer Team с App Groups и Network Extensions.

1. Перенесите папку на Mac и откройте `Aura.xcodeproj`.
2. Выберите свой Team у `Aura` и `AuraTunnel`. Свой bundle ID задайте общей настройкой `AURA_BUNDLE_ID`: идентификатор расширения и App Group наследуются от неё. Если группа уже зарегистрирована под другим именем, задайте `AURA_APP_GROUP` для обоих таргетов.
3. Схема `Aura` запускает интерфейс без ядра. Импорт, оформление, правила и копии работают независимо от VPN. Попытка запуска расширения без Libbox возвращает ошибку, а не фиктивное соединение.

Каноническая конфигурация — `project.yml`. Пересоздание через XcodeGen:

```bash
brew install xcodegen
bash Scripts/generate.sh
```

Альтернатива без XcodeGen: `node Scripts/make-project.mjs` генерирует включённый в репозиторий UI-проект.

## Сборка с VPN-ядром

```bash
brew install xcodegen go
bash Scripts/bootstrap-core.sh
open Aura.xcodeproj
```

Скрипт получает **sing-box v1.11.15** из официального репозитория, устанавливает соответствующий gomobile v0.1.4, собирает `Libbox.xcframework` и генерирует `project-core.yml`. Эта версия выбрана для фиксированного API адаптера; она **не обеспечивает паритет с актуальным Xray/Happ**. Обновление ядра и проверка безопасности перед релизом обязательны. Сборка ядра на этой Windows-машине не выполнялась; совместимость адаптера с сгенерированными заголовками нужно подтвердить в Xcode.

`active.json` записывается в App Group с файловой защитой для доступа расширения после первой разблокировки. Этот рабочий файл содержит ключи конфигурации; постоянное хранилище приложения и резервные копии шифруются отдельно. Нельзя публиковать App Group-файлы или полный системный лог с конфигурациями.

## Проверка

На Mac, после генерации проекта:

```bash
xcodebuild test -project Aura.xcodeproj -scheme Aura \
  -destination 'platform=iOS Simulator,name=iPhone 17' CODE_SIGNING_ALLOWED=NO
```

Выберите имя установленного симулятора через `xcrun simctl list devices available`. XCTest покрывает импорт, IPv6, SIP002, границы CIDR, порядок правил, шифрование и неверный пароль. CI для UI-сборки подготовлен в `.github/workflows/ios.yml`; в этой сессии он не запускался.

На Windows доступна проверка синтаксических деревьев, XML, JSON и путей:

```powershell
pip install --target .tools/python tree-sitter tree-sitter-swift pyyaml
py Scripts/validate.py
```

Для Python 3.15 может понадобиться Python 3.13: пакеты с C-расширениями должны иметь совместимые колёса. **Синтаксический разбор не подтверждает компиляцию, работу UI, соединение VPN или успешное выполнение XCTest.**

Подробный статус относительно Happ — `Docs/PARITY.md`; обязательная проверка устройства — `Docs/DEVICE-CHECKS.md`.

Проверено в текущей сессии: синтаксические деревья 23 Swift-файлов, корректность plist/entitlements, JSON ассетов и путей конфигурации проекта; `project.pbxproj` разобран независимым парсером, ссылки на файлы и три таргета проверены (`Scripts/check-project.cjs`). Xcode, Swift type checking, XCTest, камера, внешний IP и реальный VPN здесь не запускались.
